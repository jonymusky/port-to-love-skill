# Port to LÖVE

Skill de Codex para portar juegos existentes a LÖVE y Lua. Cubre equivalencia de gameplay, controles físicos, gráficos, audio, guardado y verificación del paquete. Incluye una guía específica para RG353V y PortMaster.

## Instalar

Desde una copia de este repositorio, copiá la carpeta `skills/port-to-love` a `~/.codex/skills/`. Si personalizaste `CODEX_HOME`, usá su subcarpeta `skills/`. Abrí una nueva sesión e invocá la skill con una tarea concreta.

> Usá $port-to-love para portar este juego a LÖVE 11.5 para RG353V. Conservá los modos y el guardado, y prepará el paquete para la SD.
